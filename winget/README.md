# Fiches winget

Les manifestes envoyés au catalogue [winget](https://github.com/microsoft/winget-pkgs) de Microsoft,
gardés ici pour mémoire. Une fois acceptés : `winget install Snooze561.UX-windows`.

Pour une nouvelle version : copier le dossier de la dernière version, changer `PackageVersion`,
l'adresse et l'empreinte SHA-256 de l'installateur, puis proposer le dossier à `microsoft/winget-pkgs`.
